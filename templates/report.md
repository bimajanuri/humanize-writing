# Deliverable Template — Rewrite Report

Use ONLY when the user asks for a report or when notable changes/flags must be communicated. Otherwise deliver clean text with at most 3–5 short notes.

---

## Structure

```
[rewritten text — full, clean, no markup noise]

---RINGKASAN (3–5 bullet, factual; ID output) / ---SUMMARY (EN output)
- Mode: PARA / HUM / SLOP / FACT / GRAM / EVAL / FULL | Language: id / en | Register: ...
- Diagnosis: [N] AI-pattern findings ([top 3 families]), [N] grammar issues, [N] claims checked
- Changes: [what was actually done, e.g. "removed 14 template openers; restructured 9 triads;
  fixed 6 agreement errors; cut 22% words"]
- Preserved: meaning inventory verified claim-by-claim (N claims, 0 additions, 0 drops)
- Quality: [dimension scores when EVAL is used: fidelity, grounding, correctness, naturalness, AI-pattern reduction, audience fit, completeness]
- Guardrails: [PASS / PASS_WITH_FLAGS / FAIL; literal mismatches, modality drift, or other validator results]
- Flags: [numbered list or "none"]

⚠️ Flag N (location): "quoted claim" — issue — suggested action (verify / soften to "..." / remove)
```

## Rules

- The summary is informational, never promotional ("Here's your humanized text!" is chat residue).
- Report numbers only when you actually counted (≈ is acceptable: "≈15 findings").
- Style choices you made unilaterally (register, voice, US/UK) are listed as choices, so the user can veto them.
- If the user rejected nothing and nothing was flagged, the summary can be 2 lines.
- In casual requests ("paraphrase this pls"), skip the report entirely: text + one short note if anything notable happened.

## Change-log vocabulary (use these, they're precise)

- "removed template openers/closers", "cut throat-clearing", "restructured sentence spines",
- "flattened nominalizations to verbs", "varied rhythm (sentence lengths/openings)",
- "downgraded inflated claims to their evidence level", "flagged unverifiable claims",
- "normalized register", "fixed agreement/punctuation/spelling per grammar protocol",
- "compressed bloat (X% shorter)" — only when compression was requested or slop was removed without claim loss.
