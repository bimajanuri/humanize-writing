# Citation Style Reference

Use one declared style at a time. These are operational defaults; follow the user's institution,
journal, or publisher guide when it conflicts with a general rule.

| Style | In-text convention | Reference-list convention |
|---|---|---|
| **APA 7** | Author-date: `(Smith, 2024)`; `(Smith & Lee, 2024)` | Author, year, sentence-case title, source, DOI as URL |
| **MLA 9** | Author-page: `(Smith 42)`; omit page when unavailable | Author. “Title.” Container, volume/issue, year, pages, DOI/URL |
| **Turabian** | Notes-bibliography or author-date; lock the requested system | Follow the selected Turabian notes or author-date bibliography form |
| **Vancouver** | Sequential Arabic numbers: `[1]` or superscript according to venue | Numbered order of first citation; abbreviated journal titles when required |
| **Harvard** | Author-date: `(Smith 2024)`; page for quotations | Author, year, title, journal/book details, DOI/URL |
| **Chicago** | Notes-bibliography or author-date; lock the requested system | Follow Chicago notes-bibliography or author-date form consistently |
| **IEEE** | Sequential bracketed numbers: `[1]` | Numbered order of citation; initials, title, venue, volume/issue, pages, year, DOI |

## Selection and normalization

1. Record the requested style and variant before editing.
2. Prefer the target journal or institution's current style guide over this summary.
3. Preserve source metadata and literal data; normalize punctuation, ordering, capitalization, and
   numbering only when supported by the selected style.
4. Do not use style conversion as permission to fabricate bibliographic fields.
5. Recheck citation-to-reference mapping and DOI/URL integrity after formatting.
